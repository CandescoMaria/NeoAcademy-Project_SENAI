# NeoAcademy-Project_SENAI
My first project during the Front-End Development course at SENAI.

The goal of this assignment was to customize a pre-selected template from the Figma Community, adapting it using our own creativity.

I decided to transform the provided template into a gym website, creating a unique visual identity and applying the knowledge and skills I gained throughout the course.
